# Практическая работа 3
Автоматизация резервного копирования и проверка восстановления данных.

ФИО: Белашова Эвелина
Вариант: 7

## Назначение проекта
Программа создаёт резервные копии данных, проверяет их целостность,
хранит последние 8 копий и восстанавливает данные после удаления.

Тестовые данные: отделы clients и contracts, по 10 файлов в каждом.

## Файлы проекта
- make_test_data.py — создание тестовых данных.
- backup.py — создание копий, ротация, проверка и восстановление.
- rpo_rto.md — расчёт RPO и времени восстановления.
- .gitignore — исключение тестовых данных и архивов из репозитория.

## Требования
Python 3.12 или новее.
Дополнительные библиотеки не требуются.

## Команды запуска
Все команды выполняются из папки проекта.

Создание тестовых данных:

```powershell
python make_test_data.py
```

Создание и проверка резервной копии:

```powershell
python backup.py
```

Проверка последней копии:

```powershell
python -c "from backup import BACKUP_DIR, verify_restore; verify_restore(sorted(BACKUP_DIR.glob('backup_*.tar.gz'))[-1])"
```

Восстановление из последней копии:

```powershell
python -c "from backup import BACKUP_DIR, restore; restore(sorted(BACKUP_DIR.glob('backup_*.tar.gz'))[-1])"
```

Перед восстановлением копия проходит проверку.
При успешной проверке текущая папка company_data заменяется данными
из выбранного архива.

## Примеры сообщений программы
При успешной проверке:

```text
[OK] Восстановление проверено: 20 файлов совпадают
```

При повреждении архива:

```text
[FAIL] Архив повреждён: контрольная сумма не совпадает
```

При обнаружении различий:

```text
[ЛИШНИЙ] clients\report_10.csv
[ИЗМЕНЁН] clients\report_1.csv
Итого: отсутствует — 0, лишних — 1, изменено — 1
```
